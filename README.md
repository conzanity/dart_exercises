## Scenario

A small console program that computes a student's quiz average and checks whether they pass and qualify for honors.

## What the Program Demonstrates

| Concept | Where it appears |
| --- | --- |
| `String` | `studentName` |
| `int` | `quizzesTaken`, `bonusPoints`, `stars`, `leftoverPoints` |
| `double` | `totalScore`, `averageScore` |
| `bool` | `hasCompletedLab`, `isPassing`, `qualifiesForHonors` |
| Arithmetic operators | `/`, `~/`, `%` |
| Comparison operator | `>=` |
| Logical operator | `&&` |
| Increment | `quizzesTaken++` |
| Output | `print()` with string interpolation |

## How to Run

Make sure Dart is installed (`dart --version`), then from the project folder:

```bash
dart run
```

## Sample Output

```
Student: Your Name
Average score: 85.625
Passing (>= 75)? true
Bonus stars: 3 (leftover points: 2)
Qualifies for honors? true
Quizzes taken after the new quiz: 5
```

The same output is saved in [`output.txt`](output.txt).
